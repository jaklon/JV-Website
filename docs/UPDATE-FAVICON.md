# Favicon khusus JV Story

Favicon baru memakai simbol hati warna rose dengan monogram JV, latar cream,
dan bentuk yang tetap terbaca pada tab browser. Format SVG, PNG 16/32/48 px,
serta ICO beberapa ukuran disertakan. Ikon Home Screen iPhone tetap tersedia.

1. Upload **jascon-jv-story-favicon-update-2026-10-08.zip** ke **`/home/cirj8428`**.
2. Extract ke **`/home/cirj8428`**, izinkan penggantian file aplikasi dengan nama sama.
   Struktur folder domain sudah disertakan dalam ZIP.
3. Buka `https://jascon.my.id/jv-story/` dan muat ulang halaman. Jika ikon lama masih terlihat,
   tutup tab lalu buka kembali. Referensi favicon sudah memakai versi URL baru.

Paket pembaruan hanya mengubah aplikasi JV Story beserta source backend versi terbaru.
Konfigurasi hosting, password, database, media privat, dan portofolio dipertahankan.
Paket ini menyertakan dukungan Home Screen iPhone dan implementasi Google Photos sebelumnya.
Tidak ada konfigurasi baru untuk favicon.
